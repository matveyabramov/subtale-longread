# Stage 3.3 — Experiment Architecture Fix

Status: **Awaiting Review**, 2026-10-28. Explorer interactions have not started.

Experiment is one fixed fullscreen portal layer. `#experiment` is a zero-height narrative entry marker; there are no viewport-height steps in the document flow. Instructions, Target and Result are React states, and only the selected step is mounted. Step changes update the hash and focus the named destination, with no document scrolling between steps.

Hero CTA / introduction Start / Contents / direct step hash open the layer. Forward/back controls retain their routes; Instructions Back closes it on Hero and arms the next downward wheel/touch/key gesture to reopen Instructions without repeating the intro. Result CTA and skip close it on Emptiness. Upward input crossing the start of Emptiness opens Result; one outside-boundary listener also catches residual touch momentum. Ordinary reading outside the layer stays native. Back/Forward and direct hashes select/close states without resetting outcome. The existing true-reload bootstrap clears only hash, preserves path/query and resets to Hero.

`lockPageScroll` fixes the body at its saved position and saves/restores existing inline styles, priorities and scrollbar padding. The layer and help acquire independent, idempotent releases of this same lock; closing help cannot unlock Experiment. Main/Footer are inert and the single Contents trigger is hidden/inert while the layer is open. Final exit, pagehide and unmount release the layer; pageshow reacquires it for a retained active state. Document scrolling is used only to restore/leave the layer for a reading anchor. Short-step/help content scrolls internally; edge gestures cannot chain into the page.

The layer uses `100dvh` with `100vh` fallback and safe-area padding. Its size container drives compact/low-height CSS, with media-query fallbacks. No Experiment visualViewport listeners, measured viewport variables, fractional scroll offsets or between-step alignment remain. The unrelated `--mobile-viewport` token still used by other reading sections is unchanged. Cross/dot paths, positions and opacity are static, with no timer, success detection, animation or programmed disappearance.

Figma geometry and assets are preserved from the scoped audit in session `c852f2e0-8880-4a08-b43f-6f10b7acf6e5`: 1920 `10:718/730/760`, 1440 `69:2167/2464/2493`, 768 `73:7375/7634/7663`, 390 `79:12569/12855/12816`. Mobile Back remains the first grid row at (15,15), 360×70; lower groups keep their 20px/30px gaps. All visible editorial text and the help design remain unchanged. Target retains the same instruction as its screen-reader description even while Instructions is unmounted. Keyboard focus rings remain on controls.
