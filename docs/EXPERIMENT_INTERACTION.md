Experiment is one fixed fullscreen portal layer. `#experiment` is one persistent viewport-height narrative slot between Hero and Emptiness; there are no three separately scrolling document steps. Its opaque Result visual is aria-hidden/inert and shares the active Result artwork/text without controls, focusable elements or duplicated IDs. Hero stays in normal flow. Instructions, Target and Result are React states, and only the selected step is mounted. Step changes update the hash and focus the named destination, with no document scrolling between steps.

Hero CTA / introduction Start / Contents / direct step hash open the layer. Forward/back controls retain their routes; Instructions Back closes it on Hero and arms the next downward wheel/touch/key gesture to reopen Instructions without repeating the intro. Result CTA and skip close it on Emptiness. Upward wheel/touch/key input at Emptiness checks the slot’s bottom edge, cancels default scrolling and synchronously commits Result/page lock before returning from the input handler. The outside scroll listener is only a momentum safeguard for gestures starting farther below; the opaque viewport slot buffers it from Hero. Active state guards repeated input. Result exit aligns the real Emptiness boundary after releasing the lock, with CSS-pixel rounding rather than extra layout offsets. Ordinary reading outside the layer stays native. Back/Forward and direct hashes select/close states without resetting outcome. The existing true-reload bootstrap clears only hash, preserves path/query and resets to Hero.

`lockPageScroll` fixes the body at its saved position and saves/restores existing inline styles, priorities and scrollbar padding. The layer and help acquire independent, idempotent releases of this same lock; closing help cannot unlock Experiment. Main/Footer are inert and the single Contents trigger is hidden/inert while the layer is open. Final exit, pagehide and unmount release the layer; pageshow reacquires it for a retained active state. Document scrolling is used only to restore/leave the layer for a reading anchor. Short-step/help content scrolls internally; edge gestures cannot chain into the page.

The layer uses `100dvh` with `100vh` fallback and safe-area padding. Its size container drives compact/low-height CSS, with media-query fallbacks. No Experiment visualViewport listeners, measured viewport variables, fractional scroll offsets or between-step alignment remain.
